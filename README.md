

# 🚗 Car Racing Game (JavaScript + Canvas)

A fun **2D car racing game** built using **HTML5 Canvas** and **Vanilla JavaScript**.
Dodge obstacles, collect power-ups, and race as far as you can to achieve the highest score!

## 🎮 Features

* 🛣️ **Multiple Themes** – Switch between Default, Desert, and Snow roads.
* 🚧 **Obstacles** – Cars spawn and increase in speed as difficulty rises.
* ⭐ **Power-ups**:

  * **Coin** → +50 score
  * **Shield** → Temporary protection from crashes
  * **Speed Boost** → Temporarily speeds up gameplay
* ⚡ **Boost & Brake**:

  * **Boost (↑ Arrow)** → Activate when fully charged for a 2s speed rush
  * **Brake (↓ Arrow)** → Slow down temporarily
* 🛡️ **Shield System** – Protects you for 5 seconds.
* 📊 **HUD** – Score, High Score, Distance, Level, Boost Meter, Shield Timer.
* 🎵 **Sounds** – Engine, Crash, and Coin collection audio effects.
* ⏸️ **Pause (ESC)** – Pause/resume the game anytime.
* 💾 **High Score** saved locally using `localStorage`.


## 🖥️ How to Play

* **Arrow Keys**

  * `←` → Move Left
  * `→` → Move Right
  * `↑` → Use Boost (if charged)
  * `↓` → Brake
* **ESC** → Pause/Resume
* Avoid hitting other cars 🚧
* Collect coins ⭐ for points
* Grab power-ups 🛡️⚡ to survive longer
